# Gamesa-The-mine-chaos
This is a game from collection Gamesa: PC games (games from Gam's pc)
This game is special, because on it worked actively 2 people ([Mimrpim](https://github.com/Mimrpim) Little graphics and sounds and Programming etc. and [Arthuuurd](https://github.com/Arthuuurd) Graphics and Sounds)
It is in early access and it is relatively new compare to other projects by MimrpimStudios

# Q&A
## Where is the build of the game?
> The build is not, here, because there is no stable version to release to the public. But we are close to releasing it…
## What engine are you using?
> Godot 4.5.1
## Why are you do not update on Godot 4.7/4.5.2?
> No need. Also I like this version. I started on this version. And maybe I am using some bugs as features, my code is not stable :-D
## Will be multiplayer support?
> There is a multiplayer support! But we are working on the online multiplayer support 
## Will be supported other languages than English?
> I guess not, but maybe 1 other language (Czech) could be supported
## Linux/MacOS/Web/Mobile support?
> Linux support is always planned after first few releases. I will never support Apple products yet (iOS, iPadOS, MacOS,…), because I do not have developer ID or something like that. Web support is planned, but after a stable snapshot/release. Mobile support (like Android) is planned, but after full release
